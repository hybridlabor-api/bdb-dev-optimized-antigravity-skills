How to use Antigravity Skills

Skills act as the custom instructions, guidelines, and toolsets that direct Antigravity agents. They act as "recipes of expertise" injected dynamically into the LLM context, showing the AI exactly how to solve problems, write code, or execute platform-specific actions without needing complex prompts.

Antigravity Skills

Pure system instructions, guidelines, scripts, and context files located in .gemini/config/skills/. They teach the agent *how* to think.

Model Context Protocol

External plugins configured in mcp_config.json. They give the agent *hands* to control live apps (like grandMA3, Resolume, Chrome).

Activation Steps

  • 1

    Implicit Matching

    Mention a task related to a skill. Antigravity matches the YAML metadata and loads the skill automatically.

  • 2

    Slash Commands

    Trigger complex agent configurations instantly using commands like /agentflow or /grill-me.

  • 3

    Force Usage

    Explicitly instruct the agent: "Use the [skill-name] skill to write this code..." to guarantee compliance.
